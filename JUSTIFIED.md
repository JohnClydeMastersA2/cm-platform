# Justified

The CM Platform started out as an exploratory effort, to experiment with Fastify, TypeScript, Node.js and Docker. At the time, I was looking for a framework to refactor a highly functional, very stable, but technically-dated product, the foundation of which was facing a close timeline on becoming unsupported. My most recent experience up to that point had been in developing backend applications using Java and parallel technologies. While my initial reaction was to explore a solution within my technology comfort zone, I took the opportunity to look at other options (regardless of my experience).

A couple of motivating factors that play a large role in what I hope to achieve with the CM Platform, is following the kiss principle (at all times), and also building a comprehensive solution. The first (kiss), is somewhat common, and something almost all would aspire to. A comprehensive solution, however, is somewhat about the code, but more about the environment. For example, how does a developer new to the project get a bare-bones machine up and running quickly? Likewise, how is the solution structured to accommodate developers leaving the project?

Another important aspect of a comprehensive solution (to me), is succession. In the end, how much technology can you hand off to a single person, and have them advance the effort. In looking at almost any job offer today, you will see that as engineers, we need to know it all. AI, languages, infrastructure, deployment technologies, testing approaches, security disciplines, knowledge of patterns...the list goes on.

My vision for this project, is to be able to contribute to the coding, and to do it manner that helps achieve the objectives above, and more. The fact that I'm building this from scratch, without concern for an existing production system, does not escape me.

I would be remiss not to mention my use of AI in this project. There is very little code, or documentation that I created from scratch. Instead, I have adopted the use of CODEX through a Visual Studio Code Extension. In short, I find it remarkable. Aside from the productivity gains, I find this to be one of the best educational tools I've used.

Cheers!
